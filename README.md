# Keyframe

Лендинг-портфолио студии веб-разработки. Одностраничник на чистом HTML/CSS/JS,
собирается Vite. Русская и английская версии переключаются на лету, без перезагрузки.

## Команды

```bash
npm install      # один раз
npm run dev      # локальная разработка, http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # посмотреть собранное
```

## Что где лежит

```
index.html              разметка всей страницы
src/main.js             точка входа: навигация, подключение модулей
src/scene/hero-object.js  3D-объект хиро (three.js + simplex-noise + postprocessing)
src/modules/i18n.js     переключение RU/EN
src/modules/calculator.js  калькулятор сметы
src/modules/reveal.js   появление блоков при скролле
src/i18n/dict.js        все тексты сайта, оба языка
src/styles/             токены, база, навигация, хиро, секции
public/work/            превью готовых работ
public/fonts/           локальные шрифты
scripts/                служебные скрипты, в сборку не попадают
```

Тексты правятся **только** в `src/i18n/dict.js` — в HTML они лежат как значения
по умолчанию и перезаписываются при инициализации. Если поправить их в HTML и
забыть про словарь, изменения пропадут при первом переключении языка.

Цены калькулятора — в `src/modules/calculator.js`, взяты из действующих КП
(лендинг / многостраничник / дизайн-макет, три тарифа в каждом).

## Песочница форм

`lab.html` — отдельная страница с восемью вариантами формы хиро-объекта.
Открывается на дев-сервере по адресу `/lab.html`, в сборку не попадает:
Vite собирает только `index.html`.

Отложена. На сайте стоит вариант «Резные гребни», остальные — задел на возможный
будущий раздел-витрину «что можно сделать в 3D». Рендеры всех вариантов и разбор,
чем они отличаются, лежат в [docs/shapes](docs/shapes/README.md) — чтобы посмотреть,
не поднимая песочницу.

Код: `src/lab/variants.js` (по объекту с `build()` на вариант), `src/lab/scene.js`
(общие свет, камера и блум), `src/lab/toolkit.js` (цветовая раскладка и материалы).

## Служебные скрипты

```bash
node scripts/fetch-fonts.mjs    # перекачать шрифты с Google Fonts в public/fonts
npm run shots                   # пересобрать превью трёх работ в public/work
node scripts/shot-dev.mjs       # скриншоты страницы в трёх размерах → .shots/
node scripts/audit.mjs          # контраст, табуляция, ARIA
```

Скриншоты снимаются установленным в системе Chrome, отдельный браузер не качается.

## Производительность и доступность

- Начальный JS — 9 КБ gzip. three.js с постпроцессингом (137 КБ gzip) уезжает
  в отдельный чанк и грузится после первой отрисовки; до его прихода в центре
  хиро светится CSS-подложка, поэтому пустоты не видно.
- Три профиля 3D-сцены: десктоп (полный блум, 3 октавы шума), слабое устройство
  или узкий экран (блум в половинном разрешении, 2 октавы, вчетверо меньше вершин),
  `prefers-reduced-motion` (сцена рендерит один кадр и останавливается).
- Сцена не крутится, когда хиро вне экрана или вкладка неактивна.
- Контраст текста проверен, нарушений AA нет. Вся страница проходится табом,
  фокус виден везде.

## Деплой на Netlify

Что делаю не я, а владелец аккаунта:

1. Зарегистрировать аккаунт на netlify.com (можно через GitHub).
2. **Вариант А, через Git** — залить папку проекта в репозиторий на GitHub,
   в Netlify выбрать *Add new site → Import an existing project*, указать репозиторий.
   Команду сборки и папку публикации Netlify возьмёт из `netlify.toml` сам:
   `npm run build`, публикует `dist`. Дальше каждый пуш пересобирает сайт.
3. **Вариант Б, без Git** — выполнить `npm run build` локально и перетащить
   папку `dist` на netlify.com/drop. Быстрее, но обновлять придётся вручную.
4. В *Site configuration → Change site name* задать поддомен. `keyframe` почти
   наверняка занят, из свободных по смыслу: `keyframe-studio`, `keyframe-web`,
   `keyframe-dev`, `studio-keyframe`.
5. Кастомный домен, если понадобится, — там же, *Domain management*.

Переменные окружения и API-ключи не нужны: сайт полностью статический,
формы и бэкенд отсутствуют.
