# Варианты формы хиро-объекта

Восемь силуэтов, собранных в песочнице `lab.html`. Отложены: на сайте продолжает
стоять «Резные гребни». Задел на возможный будущий раздел сайта — витрину того,
что вообще можно сделать в 3D на вебе.

Рендеры в этой папке сняты со стенда песочницы, каждый в контексте слова KEYFRAME.
Пересобрать их заново: запустить `npm run dev`, открыть `lab.html` и выполнить

```bash
node scripts/shot-variants.mjs http://localhost:5180/lab.html
```

Код вариантов — `src/lab/variants.js`, по одному объекту с `build()` на каждый.

| Файл | Вариант | Чем отличается |
|---|---|---|
| `var-blob.webp` | Клякса | Метасферы в поле marching cubes. Шесть капель летают по своим орбитам, поле пересчитывается каждый кадр: доли сливаются в одно тело и снова расходятся. Единственный вариант, у которого силуэт меняется сам по себе. |
| `var-diamond.webp` | Ромб | Октаэдр с плоскими гранями и подсвеченными рёбрами. Та же фигура, что в логотипе и что обозначает ключевой кадр на таймлайне. Лучше всех держит стоп-кадр. |
| `var-frames.webp` | Стопка кадров | Семь пластин веером, стопка наклонена — горизонтальные пластины камера видела бы с торца. Буквальная отсылка к кадрам на монтажной линейке. |
| `var-ring.webp` | Кольцо | Тор с рябью. Единственный с дыркой — сквозь неё видно буквы за объектом. |
| `var-crystal.webp` | Кристалл | Вытянутый по вертикали октаэдр. Высокий узкий силуэт, противоположность шару. |
| `var-relief.webp` | Рельеф | Наклонённая плоскость с волнами. Силуэт прямоугольный, читается как пласт, а не как тело. |
| `var-wire.webp` | Проволочный узел | Тор-узел с тонкой трубкой. Толстая с органическим шумом выглядела как внутренности. |
| `var-ridged.webp` | Резные гребни | То, что стоит на сайте сейчас. Оставлен для сравнения. |

## Если браться за раздел-витрину

Что придётся решить, чего в песочнице пока нет:

- **Производительность.** Восемь живых сцен на одной странице открывают восемь
  контекстов WebGL — браузер начнёт закрывать самые старые. В песочнице это обойдено
  так: миниатюры рисует один вспомогательный рендерер, а результат копируется
  в обычный 2D-канвас, живёт только большой стенд. Для раздела сайта логика та же.
- **Клякса дороже остальных.** Marching cubes пересобирает объёмное поле каждый кадр.
  Под неё нужны отдельные профили для мобильных и `prefers-reduced-motion`,
  как сделано для хиро в `src/scene/hero-object.js`.
- **Тексты.** Описания вариантов сейчас написаны для внутреннего пользования —
  для сайта их нужно переписать с точки зрения заказчика, а не разработчика.
